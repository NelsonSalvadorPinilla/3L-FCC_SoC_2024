# 3L-FCC

Carpeta Vitis_3adc: Proyecto de 3L-FCC usando Zybo para usar lazo de control cerrado y modulación PS-PWM. Este proyecto es el último testeado en el AC3E durante finales de 2024. 

Carpeta Modulador_IC: Proyecto con sólo el esquema de modulación PS-PWM + tiempo muerto considerando PMOS-PMOS-NMOS-NMOS. Este no contiene bloques IP de Xilinx usados en el proyecto destinado a la Zybo.
